# 번역 지침

XENON ～夢幻の肢体～ (1993, ジェネシス/Seedsware, PC-98) 일→한 번역.
1993년 일본 성인용 SF 어드벤처 게임의 팬 한국어화 프로젝트다.
기존 영문 팬 번역이 참조로 붙어 있다.

## 입력 형식 (`batches/src_NNN.txt`)

```
#NO 001                          ← 이 번역 단위의 번호
#EN <영문 참조 번역>             ← 참고용
#!! 표기 宏治→코지                ← 고유명사 강제 규칙. 반드시 따른다
//<일본어 원문>                   ← 번역 대상
```

## 출력 형식 (`batches/ko_NNN.txt`)

**`번호|한국어` 한 줄씩. 입력의 `#NO` 개수와 정확히 같은 줄 수.**

```
001|Ｂ
002|FLECTERE SI NEQUEO SUPEROS,\nACHERONTA MOVEBO.
003|천상의 신들을 움직일 수 있다면, 명계마저 움직이리라‥‥
```

- 구분자는 반각 세로줄 `|` 하나.
- 번호는 1부터 순서대로, 빠짐없이. 번호를 건너뛰거나 중복하면 병합이 실패한다.
- **번역하지 않고 원문을 그대로 둘 줄**(라틴어 인용, 로고 표기 등)은 원문을 그대로 적는다.
- 지침상 옮길 수 없는 줄은 `NNN|#SKIP` 으로 적고 보고에 이유를 쓴다.
- 한국어 안에 `|` 를 쓰지 않는다.

## ⚠️ 절대 규칙 (어기면 게임이 깨진다)

### 1. 연속 공백 3개 이상 금지
`   ` (반각 공백 3개 이상)이 들어가면 **게임이 크래시한다.**
들여쓰기가 필요하면 원문처럼 **전각 공백 `　`(U+3000)** 을 쓴다.

### 2. 제어코드를 그대로 보존
| 표기 | 뜻 |
|---|---|
| `\n` | 줄바꿈 |
| `<$04><$30>` 등 | 2바이트 게임 명령 |
| `<$05>` `<$0C>` | 1바이트 게임 명령 |

**원문에 있는 제어코드는 개수·종류를 그대로 유지한다.** 위치는 문맥에 맞게 옮겨도 되지만
빠뜨리거나 추가하면 안 된다. 예:

```
//　では、ひとつ‥‥‥<$0C>ふたつ‥‥‥‥<$0C>みっつ‥‥‥‥。
　그럼, 하나‥‥‥<$0C>둘‥‥‥‥<$0C>셋‥‥‥‥.
```

### 3. 쓰면 안 되는 문자
| 금지 | 대신 |
|---|---|
| `…` (U+2026) | `‥` (U+2025) 또는 `...` |
| `–` (U+2013) | `-` |
| `—` (U+2014) | `―` (U+2015) |

원문의 `‥‥` 는 **그대로 `‥‥`** 로 옮긴다(개수도 맞춘다). 원문의 `・・・・` 는 `‥‥` 로 바꾼다.

### 4. 길이
- 한 줄은 **최대 255바이트**. 한글 1자 = 2바이트, 영숫자/공백 = 1바이트.
- **원문(일본어)보다 길어지지 않게** 한다. 화면 한 줄은 한글 40자다.
- 원문보다 눈에 띄게 길면 문장을 압축한다. 게임이 자동 줄바꿈은 하지만 레이아웃이 흔들린다.

## 고유명사

`#!!` 힌트가 붙은 줄은 **반드시 그 표기를 쓴다.** 특히:

| 원문 | 한국어 | 언제 |
|---|---|---|
| `宏治` (한자) | **코지** | 현실 세계의 주인공 |
| `コウジ` (가타카나) | **코우지** | **기억을 잃어 자기 이름도 모르는 상태의 주인공** |

이건 작가가 의도한 서사 장치다. 한자 파트에서 「코우지」를 쓰거나, 가타카나 파트에서
「코지」를 쓰면 장면이 성립하지 않는다. 영문판은 둘 다 `Kouji` 로 뭉갰으니 **영문 참조를
따라가면 안 된다.**

| 원문 | 한국어 |
|---|---|
| `涼子` | 료코 |
| `トレイシー` | 트레이시 |
| `ランファ` | 란화 |
| `ファルネリア` | 파르네리아 |
| `ファル` | 파르 |
| `沙夜香` | 사야카 |
| `ビアンカ` | 비앙카 |
| `舞` | 마이 |
| `恵` | 메구미 |

전체 목록은 `translation/terms.json`.

## 문체

- **화자 태그** `［涼子］：` 는 형태를 유지하고 이름만 옮긴다 → `［료코］：`
  전각 대괄호 `［］` 와 전각 콜론 `：` 를 그대로 쓴다.
- **괄호 독백** `（‥‥）` 은 속마음이다. 전각 괄호를 유지한다.
- 문장부호는 한국어 관례를 따른다. `。` → `.`, `、` → `,`, `？` → `?`, `！` → `!`
  (원문이 전각 `？　` 처럼 뒤에 전각 공백을 둔 경우 그 공백은 유지한다)
- 어미는 화자에 맞춘다. 료코는 성인 여의사(주인공에게 반말~높임 혼용),
  주인공은 대학생 남성, 트레이시·란화·파르는 각자 말투가 있다. **영문 참조의 어조를 참고**하되
  일본어 원문의 경어/반말 구분을 우선한다.
- 원문에 없는 내용을 넣지 않는다. 원문에 있는 내용을 빼지 않는다.

## 성인 게임임

성인용 작품이라 성적으로 노골적인 대사가 나온다. 기존에 출판된 저작물의 **번역 작업**이므로
원문에 충실하게 옮긴다. 다만 미성년자가 관련된 성적 묘사로 읽히는 대목이 있으면
**번역하지 말고 빈 줄로 두고 배치 보고에 해당 줄을 적어 올린다.**

## 참고

- 영문 참조(`#EN`)는 의미 파악용이다. 오역·오타·화자 오배정이 실제로 있다
  (`Kouij`, `Ryoulo`, `［涼子］→Kouji` 2줄, `［恵］→Mai` 2줄).
  **일본어 원문이 언제나 기준이다.**
- 같은 대사가 여러 번 나오는 경우가 많다(중복 대사 4,599회). 같은 원문은 같게 옮긴다.
