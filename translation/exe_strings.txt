# AGS.EXE 안에 하드코딩된 일본어 UI 문구의 번역
#
# 형식은 다른 작업 파일과 같다. '//일본어' 다음 줄에 한국어.
# '#' 로 시작하는 줄은 주석.
#
# ⛔ 바이트 제약 — 문자열이 서로 맞붙어 있어 **원본 바이트 수를 넘을 수 없다.**
#    한 글자 = 2바이트(한글도 일본어도 같다). 즉 글자 수를 원본 이하로 맞춘다.
#    tools/exe_patch.py 가 초과하면 거부한다.
#
# 전각 공백(　U+3000)은 원본의 여백/정렬이다. 되도록 유지한다.
#
# 조사·근거: gfx/EXE_STRINGS.md

# ============================================================
# 1) 종료 메뉴 — 플레이 중 자주 보인다
# ============================================================
# 원문 앞뒤의 전각 공백까지 포함해야 EXE 에서 NUL 로 끝나는 한 문자열이 된다.
# (「　ゲーム終了」만 쓰면 「　ゲーム終了　」와 「ゲーム終了後に…」 양쪽에 걸려 모호해진다)
//　キャンセル　
　　취소　

//　最初に戻る　
　처음으로　

//　ゲーム終了　
　게임 종료　

//　このままゲームを続ける。
　이대로 계속한다.

//　本当にゲームを終了する。
　정말로 종료한다.

# ============================================================
# 2) 스페셜 모드 — 레이디스 룸 잠금 안내 (실기 확인된 문구)
#    앞의 전각 공백 8개는 가운데 정렬용이다. 글자 수에 맞춰 줄였다.
# ============================================================
//　　　　　　　　ゲーム終了後にお楽しみ下さい
　　　　　　　　게임을 끝낸 뒤에 즐겨 주세요

# ============================================================
# 3) 디스크·파일 오류 안내
#    HDD 설치본에서는 대개 안 뜨지만, 뜨면 일본어가 그대로 보인다.
# ============================================================
//ディスクをセットして下さい
디스크를 넣어 주세요

//ディスクをドライブ２へ入れて下さい
디스크를 드라이브 ２에 넣어 주세요

//をドライブ２へセットして下さい
를 드라이브 ２에 넣어 주세요

//データがセーブされていません
저장된 데이터가 없습니다

//ゲームディスクではありません
게임 디스크가 아닙니다

//ディスクが違います
디스크가 다릅니다

//ディスクへ書き込みができません
디스크에 기록할 수 없습니다

//ファイルがオープンできません
파일을 열 수 없습니다

# ============================================================
# 4) 음원
# ============================================================
//音色データーを転送中です
음색 데이터 전송 중

//効果音ファイルをオープンできません
효과음 파일을 열 수 없습니다

# ============================================================
# 5) 디스크 이름 (Ａ~Ｅ). 원본이 전각 라틴 + 「ディスク」
# ============================================================
//Ａディスク
Ａ디스크

//Ｂディスク
Ｂ디스크

//Ｃディスク
Ｃ디스크

//Ｄディスク
Ｄ디스크

//Ｅディスク
Ｅ디스크
