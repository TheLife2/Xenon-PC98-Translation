# 검수 지침

이미 번역이 끝난 한국어를 **문체·자연스러움 관점에서 다듬는** 작업이다.
번역을 새로 하는 게 아니다. 뜻이 맞는 줄은 건드리지 않는다.

---

## ⚠️ 1순위 — 어체(경어 등급) 일관성

한국어는 한 화자가 같은 상대에게 말할 때 어체를 섞으면 즉시 어색해진다.
일본어 원문은 보통체와 정중체가 자연스럽게 섞이므로, 그대로 옮기면 이 문제가 생긴다.

### 실측된 문제

```
［코지］：그렇습니다, 가위에 눌리고 있어요.        ← 한 문장 안에서 합쇼체+해요체
［코지］：그곳은, 어둡고 쓸쓸한 곳이었습니다‥‥.     ← 합쇼체
［코지］：어느새, 보일러실 같은 곳에 있었어요‥‥.    ← 같은 장면, 같은 상대인데 해요체
```

`［宏治］` 대사 1,662줄 중 합쇼체 53 / 해요체 68 — **혼용도 43.8%**.
`［トレイシー］` 985줄 중 합쇼 83 / 해요 231 — 26.4%.

### 화자별 확정 어체

| 화자 | 상대 | 어체 | 비고 |
|---|---|---|---|
| `［宏治］` 코지 | 료코(의사·연상) | **해요체** | `-습니다` → `-어요/-예요`. 대학생이 주치의에게 쓰는 자연스러운 말 |
| `［宏治］` 코지 | 마이·메구미·사야카 | 원문의 친소를 따름 | 또래. 반말~해요체 |
| `［コウジ］` 코우지 | 전원 | **하대·반말** | 정신지배 인격. 이미 일관됨(합쇼 1줄뿐) |
| `［涼子］` 료코 | 코지(현실 파트) | **반말** | |
| `［涼子］` 료코 | 프로페서 / 「宏治様」 구간 | 존댓말 | 이미 확정됨. 건드리지 말 것 |
| `［トレイシー］` 트레이시 | 프로페서 | 합쇼체 허용 | 상급자 보고. 「알겠습니다」류 |
| `［トレイシー］` 트레이시 | 코지 | **해요체** | |
| `［ランファ］` 란화 | 코지 | **해요체** | 이미 대부분 일관(6.4%) |
| `［舞］` 마이 | 코지 | **해요체** | 이미 일관 |
| `［ファル］` 파르 | 코지 | 반말 | 이미 일관 |
| `［恵］`·`［沙夜香］` | — | 원문을 따름 | |

### 절대 규칙

**한 문장(한 줄) 안에서 합쇼체와 해요체를 섞지 않는다.**
`그렇습니다, ~있어요` → `그래요, ~있어요` 처럼 한쪽으로 맞춘다.

## 2순위 — 그 밖의 문체 문제

- **일본어 직역투** : 「~라는 것이다」, 「~하는 것이 좋다고 생각한다」, 「~에 다름 아니다」
- **번역투 조사** : 「~에 있어서」, 「~에 의해」 남용
- **관용구 직역** : 「下の下 → 최하의 최하」 같은 것 (이미 「최하급이지」로 고침)
- **부자연스러운 어순** : 일본어 어순을 그대로 옮긴 것
- **화자 어긋남** : 대사 내용과 화자 태그가 안 맞으면 보고만 하고 고치지 말 것

---

## 손대면 안 되는 것

- **`//` 줄(일본어 원문)** — 절대 수정 금지
- **`<$XX>` 제어코드, `\n`** — 개수·종류를 그대로
- **고유명사** — `translation/GLOSSARY.md` 확정본. 특히 `宏治`=코지 / `コウジ`=코우지
- **확정 용어** — `translation/terms.json` (흡착판·팩터·퇴행 욕구·정신적 가치)
- **의성어** — `translation/sfx.json` 표준표로 이미 정규화됨. 순수 의성어 줄은 건드리지 말 것
- **연속 공백 3개 이상 금지** (게임 크래시), `…`(U+2026)·`–`·`—` 금지
- **한 줄 255바이트** 이내, 원문보다 크게 길어지지 않게

## 입출력

입력 `translation/review/rv_NNN.txt`
```
#NO 001
#JP ［宏治］：あそこは、暗く寂しい場所でした‥‥‥‥。
#KO ［코지］：그곳은, 어둡고 쓸쓸한 곳이었습니다‥‥‥‥.
```

출력 `translation/review/fix_NNN.txt` — **고칠 줄만** 적는다.
```
001|［코지］：그곳은, 어둡고 쓸쓸한 곳이었어요‥‥‥‥.
```

- 고칠 게 없으면 빈 파일을 만든다.
- 번호는 입력의 `#NO` 와 같아야 한다.
- 한국어 안에 `|` 를 쓰지 않는다.
- 뜻이 맞는데 취향 차이일 뿐인 줄은 고치지 않는다. **어체 일관성과 명백한 어색함만** 손댄다.
